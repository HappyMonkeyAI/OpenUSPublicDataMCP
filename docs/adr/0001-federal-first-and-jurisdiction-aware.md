# ADR 0001: Federal-first and jurisdiction-aware expansion

- Status: accepted
- Date: 2026-07-11

## Decision

Start with official federal APIs and catalogue metadata. Add state/local coverage through reusable platform adapters plus curated jurisdiction-specific modules. Do not promise uniform US-wide coverage.

## Consequences

The first release is smaller but reliable. State/local growth requires explicit provenance and coverage metadata, while avoiding 50 duplicated implementations.
